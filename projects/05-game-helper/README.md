# 第五人格小抄机

> 把游戏里要反复查的「侧门位置 → 走哪条路」做成一张随时能翻的小抄：
> 纯前端、零依赖、不联网，手机和电脑各一版。

## 背景与目标

- 场景：打《第五人格》时，进图要先判断地形和侧门位置，再决定走哪条路
- 原来的做法：切出去看视频或图文攻略，游戏全屏时被打断
- 目标：一张图一个条目，按地形和侧门位置能直接翻到；不离开游戏就能看

## 我做了什么

- 需求拆解：把「地形 → 侧门位置 → 路线」定成三级结构，一个条目对应一张点位图
- 方案：纯前端单页 + 数据文件分离。`data.js` 存整棵目录树，手机版和看屏版两个 HTML 都读它，加路线只改这一个文件
- 关键实现：`data.js` 里是嵌套对象，叶子节点挂图片文件名；页面拿这棵树做逐级下钻——先选地形，再选侧门位置，最后进到某条路线，点进点出
- 关键实现：两个版本共用一份数据——手机版按移动端排布、单手点进点出；看屏版固定一屏高度、带页头，游戏全屏时 Alt+Tab 瞄一眼
- 关键实现：每条路线一个主图 + 两张细节放大图（`img17.jpg` / `img17_1.png` / `img17_2.png`），顶部三个按钮切换
- 内容规模：1 张地图（厄运之女 · 困难）、8 种地形、29 条路线、87 张点位图（含放大版）

## 结果

- 覆盖「厄运之女 · 困难」全部 8 种地形的 29 条常见路线
- 数据与页面分离，后来补路线只改 `data.js`，两个版本同时生效
- 实际使用频率：未统计
- 已知局限：点位是手游版本更新前整理的，赛季地图调整后可能过期；打包的 exe 是 0.3 版，比 HTML 版旧

> 说明：这是「速查小抄」，不是外挂，不读取游戏内存、不修改游戏数据、不自动操作。

## 技术栈

- 纯 HTML + CSS + JavaScript，无框架、无构建
- 数据用 JS 对象字面量（`data.js`）直接引入，不请求接口
- 电脑版用打包工具封成独立 exe，免装环境

## 怎么用

- **手机**：把 `手机版\` 整个文件夹传到手机，浏览器打开 `加页小抄机（手机）.html`
- **电脑**：双击 `电脑版\加页小抄机pc升级版0.3.exe`，不用配环境
- **改内容**：只改 `手机版\data.js`，两个 HTML 都会跟着变
